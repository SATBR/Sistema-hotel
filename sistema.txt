O sistema deve ter:
1. Cadastro de hóspedes

Cada hóspede deve possuir:

Nome
CPF
Telefone
Email
Data de nascimento
Cidade
Observações

Você deve conseguir:

Cadastrar
Editar
Excluir
Pesquisar
2. Cadastro de quartos

Cada quarto deve possuir:

Número
Tipo (Solteiro, Casal, Luxo...)
Valor diária
Quantidade de camas
Ar-condicionado (Sim/Não)
TV
Wi-Fi
Situação

Situação:

Livre
Ocupado
Em limpeza
Reservado
3. Sistema de reservas

Essa é a parte interessante.

O usuário escolhe:

Hóspede
Quarto
Data de entrada
Data de saída

O sistema precisa verificar:

O quarto está livre?
Já existe reserva nesse período?
A data de saída é maior que a entrada?

Se tudo estiver correto:

Reserva criada.

Caso contrário:

Mensagem de erro.

4. Check-in

Ao fazer check-in:

muda o status do quarto para "Ocupado"
registra horário
registra funcionário (pode ser fictício)
colocar no check-in
 id: 1,
    cpfCliente: "12345678900",
    numeroQuarto: 101,
    idReserva: 1,
    dataHora: "2026-08-10T14:32:00",
    usuarioSistema: "recepcao01",
    status: "Ativo"
    
5. Check-out

Quando o cliente sair:

O sistema calcula automaticamente:

Quantidade de dias

x

Valor da diária

=

Total

Depois:

libera o quarto
salva histórico

pelo nome

Quartos livres
